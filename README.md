🌍 About the Project | 项目介绍

Daily Cognition OS is an open-source AI-powered cognitive development system designed to help people improve their thinking, understand the world, make better decisions, and develop lifelong learning habits.

Daily Cognition OS 是一个开源 AI 认知成长系统，旨在帮助人们提升思维能力、理解世界、改善决策，并建立终身学习习惯。

我们相信：

知识的价值不在于记住多少，而在于能否理解、质疑、运用，并最终转化为自己的能力。

🧠 Core Learning System | 核心学习体系

1. Daily Cognitive Lessons | 每日认知课程

围绕六大领域开展学习：

- Thinking & Logic — 思维与逻辑
- Wealth & Economics — 财富与经济
- Human Nature — 人性洞察
- Fundamental Principles — 底层逻辑
- Independent Thinking — 独立思考
- Decision Making — 决策能力

2. Five-Step Learning Method | 五步学习法

1. Understand — 理解：用自己的语言解释核心观点。
2. Recall — 复述：不看原文，主动回忆知识。
3. Connect — 联系现实：找到实际应用场景。
4. Challenge — 主动质疑：寻找观点的局限、条件和反例。
5. Review — 间隔复习：通过周期性回忆巩固知识。

建议复习节点：第1、4、7、15、30天。

3. AI Feedback System | AI 反馈机制

AI 不只是提供答案，更应该成为学习者的思维教练。

每次回答后，AI 应当：

- 评价理解是否准确。
- 指出逻辑漏洞。
- 发现遗漏的关键因素。
- 提出进一步思考的问题。
- 提供可执行的改进建议。

4. Continuous Growth | 持续成长

记录学习进度、复习情况、知识掌握程度和思维变化。

目标不是完成多少课程，而是真正提高独立思考和解决问题的能力。
